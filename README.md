# 📝 Sticky Notes App

A modern and professional Sticky Notes Web Application built using HTML, CSS, and JavaScript.

This app allows users to create, edit, save, and delete sticky notes with a beautiful modern UI and Local Storage support.

## 🌐 Live Demo

🚀 Live Website:  
https://sunnysaini2004.github.io/sticky-notes-app/



Modern glassmorphism UI with:
- Sticky notes
- Local storage
- Responsive design
- Professional color palette
- Smooth animations
- Minimalist interface

# ⚙️ How It Works

## Add Notes
Click the `+ New Note` button to create a new sticky note.

## Save Notes
Notes are automatically saved in the browser using Local Storage.

## Delete Notes
Double-click on a note to delete it.
